# 中英表演翻译规范

这是sound-design的通用能力规范：将中文创作意图转为目标模型能执行的英文表演描述。凡当前执行端使用英文表演提示，均在编译前应用；中文台词仍按合同保留。范围包括TTS及原生声画模型，不将某个模型的标签或成功形容词当成通用接口。

## 1. 理解中文语用与表演任务

结合前后对白回答：谁对谁说、表层说什么、真正想改变对方什么、人物关系和地位如何、哪些话说给全场而哪些暗示针对特定听者。区分字面情绪、真实意图和人物正在掩饰的情绪；没有证据不添加潜台词。

识别反讽、客套、试探、安抚、施压、示弱、欲言又止等语用作用。将一句话拆成有意义的表演推进，说明起点、转折、落点；标点不直接等于语气、重音或固定静默。优先沿用用户已确认的解读，语境缺口会改变表演时才问关键问题。

## 2. 选择英文情绪词与修饰组合

英文选词以忠实且可表演为准，不能停在中文形容词逐字对译。综合以下维度选择当前句真正需要的信息：

| 维度 | 翻译必须保留的内容 |
|---|---|
| 情绪性质 | 真正的心理状态与交际态度，不把质疑误成愤怒、克制误成冷漠 |
| 意图与对象 | 在试探、说服、警告或安慰谁；希望对方怎样回应 |
| 程度与外显 | 情绪有多强、露出多少，是否压住或仅一瞬透出 |
| 内外层次 | 表面态度与内在意图是否并存，谁是外层、谁是底层 |
| 关系与语体 | 权势、亲疏、礼貌、亲昵和讽刺程度，不擅改角色身份 |
| 时间推进 | 从哪个词开始变化、怎样推进、在哪里收住 |

形容词确定质地，副词限定力度与分寸，表演动词明确人物在对听者做什么；必要时用自然短句明确内外关系和时间转折。选足以区分当前意图的精准词，不为复杂而堆罕见词或互相抵消的标签。可比较少量候选表述的意思，选择最贴合的一版，无需因此默认新增付费样本。

## 3. 中文回译核对

按英文实际表达回译，不照抄最初中文意图。逐项核对：听者、劝说方向、情绪性质、强度、内外层次、词句转折和人物关系是否一致。英文多义词、副词附着位置及修饰范围不清时，改成更明确的自然表达；同一个词被用于不同含义时按当前语境重新选。

回译造成说话目的改变、指向错人、强度升级、讽刺变嘲弄或克制变无情，均须先修正英文。回译通过只是文本语义检查，不是对模型生成效果的证明。

## 4. 转成可听、可见的执行描述

将英文表演描述对齐到原文完整词或短语，说明重点及轻带陪衬，以及起音、局部音高走势、强弱、时值、速度变化与句末收声。重音不自动等于更响；轻读保留清晰度和正常字调。形容词必须能落到具体声音变化，避免整句一个标签、全程同样处理。

持续有声延音与无声停顿分别翻译：前者明确元音连续发声并接下词，后者明确何处停止发声；省略号与换行不提供精确时长保证。依服务实际能力表达，不发明不存在的词级端口、SSML或强度参数。把转念与视线、动作和接话配合，但不能让动作说明取代声音表演。

应说中文、说话人、角色声线身份和合同范围保持一致。英文描述、回译和舞台指示置于执行端的说明区；台词区仅放应说正文。H3标签等格式按对应服务参考编译，不套给其他执行端。

## 5. 最小交接与验收

相关交接至少能读出以下四项，可复用现有声音字段：

- 中文意图：含对象、关系、潜台词及情绪推进。
- 英文表演：选定的情绪词、修饰组合、交际动作及变化关系。
- 英文词级执行：具体对应原文哪些词、怎样轻重起落、延音或停声。
- 中文回译结论：对照原意是否一致，歧义怎样消除；未解决项如实保留。

先做文本和当前服务格式检查，再按现有授权执行。试听核对语义目的、词级轻重、真实说话感、角色声线和口型；不以提示词、ASR或声学曲线代替实际听核。翻译标准本身不要求新一轮审批或额外计费样本；遇到明确偏差，按现有停止和授权边界修订。

## 方法与案例的关系

此流程是常规能力要求，不以某条样片成功为启用前提。已有案例仅帮助校准选词分寸和排查误译；新语境需要重新理解、选词、回译及表演化，不复用案例的固定词组、镜数或时长。H3具体格式和项目实例按需查 [H3原生对白参考](h3-native-speaker-format.md)，中文语义与轻重方法见 [语义与词级表演](semantic-word-prosody.md)。
