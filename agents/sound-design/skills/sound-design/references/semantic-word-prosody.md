# 语义与词级表演

本方法由用户2026-10-21明确要求：先理解中文含义、按含义组织意群，再把重音、轻音与情绪变化落实到具体词。它适用于对白设计和原声参考学习；具体样本效果仍需实际试听，不能用文档或声学曲线冒充。

## 先定语义焦点

从前后问答和人物目的识别已知信息、新增信息、对比或反驳。意群按意义成立，停连服务意图，不能把标点逐个换成固定静音。检查焦点时问“换一个重读词，意思会怎样变化”。例如“你有钱”：重“你”指认对象，重“有”纠正否认，重“钱”强调资源；这是假设读法对照，不是某段录音的实测结论。

## 先分清表层话与潜台词

含客套、双关或借物劝说的句子，先说明主要听者、表层意思、真实劝说目标和希望对方下一步怎样回应，再决定情绪及重点词。角色在“催饭”时，可能是在给对方留台阶、提醒把握交易时机；不能只因菜凉或句末感叹，就推断说话人嫌烦、饿了或抱怨。用户纠正语境后，应同步改正意图、情绪词、重音、视线和动作，避免只替换一个形容词。

复合情绪必须能拆成可执行的表演变化，并对应到实际词语及轻读陪衬，而非整句套一个情绪标签。中文要求需编译为英文时，每次应用 [中英表演翻译规范](performance-translation.md)：解析意图与对象、精准选择英文情绪和修饰组合、中文回译核对、落实词级表演。该流程独立于具体模型和样片；项目案例仅用于校准。

## 再定词级处理

- 给重点词配置清楚的起音、轻重、时值、局部语调、收紧或留隙，并安排其他词怎样轻带。一个句法骨架不必处处强调；长句可以有多个语义动作，主次关系服从语境。
- 情绪写到词的进入、转折、退出：前导可以礼貌轻快，重点词稍撑并透出包办意味，随后收住等对方接话。声音在句内变化，不依靠句末标点才换情绪。
- 轻重是相对关系。更响、更高、更长只是可能手段，重点词也可通过低而笃定的处理成立；陪衬轻带仍须清楚。轻读不等于全部改读普通话轻声，语调不改坏四声。
- 把词作为有意义的整体组织，例如“省心”“登录”不拆成每字一拍。不为了表现重音临时在词内添加逗号、空格或夸张破折号，避免合成器机械断开。

## 可用的最小记录

在现有声音交接字段中表达以下内容即可，无需机械新增JSON键：

| 内容 | 要回答的问题 |
|---|---|
| intent / 语义意群 | 回应什么？想让对方怎么想或怎么做？ |
| 焦点与陪衬 | 哪个词承载新增、对比、反驳或包袱？其余词如何轻带？ |
| word delivery / 情绪路径 | 重点词怎样起、撑、转、收？情绪在具体哪个词发生变化？ |
| 停连与接话 | 停顿为何必要？哪里可以跨标点连读？ |
| 证据状态 | 设计、自动转写、词界估计、声学观测、已听核分别是什么？ |

## 参考学习与验证

保留原件、来源和哈希；分析副本记录格式、采样率与时长。先核准文本和说话人，再使用词界辅助回放；自动合并的词组不能假称已分别测准单字边界。上下文提示可改善也可诱导ASR，保留原始识别和疑点，不以提示后的文字作成功证明。

音高、RMS和时值用于定位收放，结合语义与实际听感解释。字调、音域、混音、配乐、发音结构及跟踪错误都会影响数值，不跨演员按绝对F0或响度排序，也不把曲线峰值直接命名为语义重音。

样本核对先听正文/声线，再听重点词与陪衬是否传出预期意思，最后检查词内情绪、接话与画面动作。声学数值或ASR通过不等于抑扬顿挫、角色归属和嘴型通过。样本没有直接听核时明确保留限制。

原生有声服务若只暴露提示词，词级表演谱只是一份创作输入；不能宣称它拥有独立词级重音控制端口。保留已认可的节奏/画面，按当前批准范围做定向修订；不因本方法额外创建付费探针、复制原片演员音色或默认追加TTS/口型任务。
