# 动作设计 Skill V3.1

先看实际图片，再设计动作；不是给每个物件随机加一个动词。覆盖所有有独立表达、生命或受力关系的主体，但不要求所有主体都动。

人物姿势本身属于动作设计：静态关键帧也要检查受力牵引、支撑与重心、关节可达性、肌肉发力/稳定及前后动作衔接。先确定动作所处阶段，再推导整身姿态；不得仅凭轮廓好看、武器方向相似或提示词写对就判通过。

已认可静态姿势是动作中的状态，不能默认锁成全程不变的肢体模板。对飞来/冲刺等动作，同时设计整体空间路径和肩胸骨盆、肘腕、髋膝踝的受力调整与肌肉稳定功能，并独立核对人物到摄影机的深度、投影大小及遮挡变化；不能用固定剪影的平移/缩放或环境运动代替人物表演。

## 输入与责任

动作审核粒度落到镜头内每个可见主要部件，不能止于“人物/物体整体”。沿用整体subject_id承载身份和轨迹，在其下列出主要部件part_id及父级、可见性、动作/稳定职责和联动；手、表情、腰、腿等不能被整体“飞行”一句覆盖。部件共享骨架与受力约束，不独立随机运动。遮挡或景别不可读的细节标出边界，不为展示细节擅改机位。

从总控取得当前 shot_id、静态图路径/版本、镜头表达与已定故事、时长、景别/摄影机合同、场景主体表及必要的连续性/声音同步点。只加载本镜，不要全片历史或所有专业 Skill。若尚未看图，必须先查看；图不存在或看不清的关键连接返回总控，不能仅凭提示词假装完成图像审核。

故事创作、改时长和改认可图由总控决定；场景角色负责绘制与空间事实；本角色负责动作及其可见证据；提示词角色编译，节点角色核对可实现控制。视频执行前仍经过方案库，不自行选供应商或生成。

## 最小工作顺序

1. **读图建表。** 沿用场景的 subject_audit 与稳定 subject_id，检查前中后景、边缘、雾中和部分遮挡。记录位置、姿态、可见部件、材质/生命设定、支撑与连接；分开可见事实、上游设定、假设和未知。单张图不能证明速度、过去动作、隐藏关节或真实刚度。
2. **决定作用与状态。** 按导演表达，为每主体选择主动运动、被动响应、局部变化、本镜静止或待判断，并说明理由。数量众多的同类粒子可分组；独立人物、生命体或不同受力物体不能粗暴合并。技术困难不是悄悄冻结主体的理由。
3. **写动作卡。** 从初始姿态推导可达动作，分开整体路径、局部关节/形变与摄影机引起的屏幕变化。动作必须包括驱动/意图、作用点或朝向、路径参照、速度变化、时间形态、次数、停止条件和末态。接触动作写支撑、重心/受力转移和遮挡；不凭空补绳索/铰链。
4. **联成全图时序。** 写驱动→响应→连带→衰减；有联系才联动，独立风浪与呼吸不强行同频。安排串行、并行或错峰，留出停稳/观看时间；巨大尺度感需结合路径与参照推导，不能一律慢动作。主事件清楚，必要次级响应不能为省事删掉。
5. **检查能否看见。** 相对固定地标核对主体运动，避免以整图平移冒充。一次动作不能被默认循环；经过节点不自动插入停顿，只有表达需要停稳/观看时才安排保持段，取段必须保留承重节拍与可读结果。秒数是设计目标，不承诺生成模型精确执行。
6. **输出并交接。** 使用 [动作包](references/action-package.md)，把逐主体动作补回原 subject_audit，不另造重复台账。简单单镜可用短表；复杂接触/路径采用可审阅预演，预演未实际进入节点时只称本地参考。设计完成不代表视频已验收。

## 按需方法

- 连续绕行/快速位移、阶段衔接停顿、尺度朝向漂移或特效掩盖动作时：读 [连续动作、一致性与镜头叙事复盘](../../../../references/action-continuity-shot-narrative.md)。只使用命中的动作与一致性部分，不把节点图当成全程固定姿势，也不把具体路径次数推广为通用模板。

- 动作转成生成提示词，或结果出现贴图感、姿势冻结、镜头与身体运动混淆：读 [动作提示词编译与校准](references/action-prompt-translation.md)。先写状态差与可见证据，再交给提示词角色；身份不变不等于姿态不变。

- 人物姿势设计、姿态纠错或关键帧审核：读 [姿势、受力与身体经验](references/pose-and-physical-experience.md)。把受力、关节、肌肉功能及遮挡落实到可见证据；将人审校准和参考学习积累成带适用条件的经验。
- 新静态图/陌生主体、多主体交互：读 [静态图到动作](references/static-image-to-action.md)。
- 风浪、浮桥、活体建筑、呼吸、材料联动：读 [已确认经验](references/motion-systems.md)。
- 字段、时间和给提示词的交接：读 [动作包](references/action-package.md)。
- 要研究/增加控制手段时：读 [开源来源索引](references/open-source-learning.md)，仅查相关项目；不自动安装、上传或调用。
- 要从参考视频提炼动作时：读 [视频动作解析学习资料](references/video-motion-analysis.md)。先分镜、解释事件并附原始帧证据，再按需用姿态/轨迹工具复核；这不是重做预演，也不代表工具已经安装。来源、推断与许可边界分开记录。
- 角色替换或面部表演影响镜头表达时：读 [表情与动作联合设计](references/expression-action.md)。身份不变与表情不变是两件事；将视线、面部、身体和镜头节拍一起设计，保留参考视频对具体方法的证据边界。
- 有绳索、钩锁、安全带或其他外力牵引主体，并同时安排挥砍/投掷等蓄力动作时：读 [牵引点与身体动力链](references/grapple-traction-sword-load.md)。先确定受力点和力线，再设计骨盆、胸腔、肩肘腕的先后；具体招式只限当前镜头，不升级为通用姿势。
- 全图覆盖与导演表达的共同标准：`../../../../references/subject-intent-motion-review.md`。这是现有静态/合同/最终人审内的检查，不新增门禁。

## 验收边界

保持身份、数量、刚性形状与合法接触。静止要有理由；刚性不等于固定位置；雾动不等于被遮挡主体动；镜头连续不等于每个主体全程运动。第一视角关键手部与接触面一起表现，不能以剪贴手替代承重表演。

有冲突只返回相关对象、缺口和最小建议；不擅改故事、不堆动作掩盖坏图，不自行重试。服从总控当前项目明确授权与停止策略，不能把特定项目的有界重做推广到其他项目。
