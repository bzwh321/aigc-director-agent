# 最小动作包与交接

一镜一包，V3.1。可以在现有 scene_package / 合同内直接补充，不强制建立新文件。简单单镜用表即可；不要求所有主体有坐标数值或所有动作逐帧量化。

## 必要内容

- `shot_id`、输入图引用/版本、`duration_seconds`、`intent`：上游已定，不自行改写故事。
- `subject_audit[]`：沿用场景ID和定位，区分观察、设定、假设、未知；每项补 `motion_decision`、理由、动作卡及可见验收。选择 `active / passive / local_change / hold / unresolved`。未决项写承重缺口。
- `parts[]`：附在有可见主要部件的主体下，不新建重复人物；字段为part_id、parent_id、visible/partial/occluded、本镜职责、相对父级及相邻部件的动作状态差、触发/时序、接触约束、可见验收。按镜头重要性覆盖主要部件，不要求逐肌纤维或逐手指拆解。每个主要可见部件有持续的动作/控制说明，稳定、被动响应和一次动作后的保持也应有理由；不可读细节不声称已验证。
- 动作卡：起态、驱动/触发、作用部位、相对路径、速度/幅度、时间形态、次数/重复、接触与联动、停止条件、末态、不变项。静止可用“全镜保持＋理由”，无需伪造驱动和路径。
- `motion_system`：独立驱动与已证实/假设关系，次级响应、保持对象和原因。
- `beats[]`：沿用start/end/subject/camera/contact，补subject_ids；主体事件可并行，镜头总节拍覆盖0到本镜结束，不超时。预备、动作、停稳/持续状态按需要编排，不强制每镜同一节拍数。
- `camera`：与主体运动独立；机位、旋转、位移、焦段和运动停止后的状态，服从镜头设计。
- `previs`：required、理由、path、status（not_needed/planned/available）、哪些关系可验证。只有实际文件与端口证据才可写“已输入模型”。
- `acceptance`、`open_questions`：静止与运动都可被观看确认；给提示词的是精简动作合同，而非所有来源全文。

完整主体表太长时，包里给权威文件路径/版本和承重主体摘要，角色按需读取，不截断为“只关注主角”。静态图替换后重新核对主体及动作可行性，不能只沿用同名文件。

## 文字推演示例：闸门开启后的担忧

**纯虚构输入说明，用于检查方法，不是本轮看过的实际图片或生成结果。** 上游给定8秒：闸门已部分开启，浪涌入，工程师担心结构失稳；画面有工程师、闸门、水、浮台、明确可见的系泊链、固定塔体。固定机位。若实际图没有链，不得照搬下表新增链。

| 主体 | 决定与依据 | 起止/联动 | 可见验收 |
|---|---|---|---|
| E01 工程师 | 主动单次观察，表现担忧；脚不换位 | 0–1秒看水；1–2.5秒抬眼看门；2.5–8秒保持凝视并克制呼吸 | 头/视线相对门变化，脚底不滑；不是反复摇头 |
| G01 闸门 | 本镜保持；上游定义它已到当前开度 | 0–8秒开度固定，不擅自继续开启 | 与轨道固定参照的间距稳定 |
| W01 水 | 压差驱动持续流动，作为主要环境运动 | 全镜涌流；2秒附近较强波峰是设计节拍，不承诺精确模型时刻 | 水从开口进入，不穿固定塔体 |
| P01 浮台 | 被动响应，与固定岸区别 | 波峰到达后升降并轻微俯仰，随水继续而不全镜定格 | 相对水面/岸体变化，结构不融化 |
| C01 链 | 被动牵制，依据图中明确连接 | 浮台外移时绷紧，回落时相应放松；不无故独立甩动 | 两端连接不脱离；响应不早于牵拉 |
| T01 塔体 | 固定基础，无需为证明危机而强行摇晃 | 全镜保持；可利用既有裂纹/水迹作静态线索 | 稳定参照，不能与浮台同频上下移动 |

总节拍：0–1秒建立；1–2.5秒视线转移与环境涌流并行；2.5–4秒留观众观察联动；4–8秒工程师保持，环境继续。声音只列必要同步点，不能为了声音重写已锁定时轴。

## 反例校准

1. “所有建筑保持静止”会误伤故事定义为活体的巨构：按主体/部件指名约束，硬壳保持形状但可有关节整体运动。
2. “所有物体全程持续运动”会抹掉一次抬升后的停顿：按主体记录时间形态与末态，提示词不得覆盖。
3. 一张图中的脚被遮挡：可以设计可见上身反应；若剧情必须走动/接触，向总控提出补图或预演，不伪造看见脚底支撑。
4. 遥远的活体被雾遮住：低幅运动须相对固定地标可读；只让雾飘不算主体已动。是否必须动由故事决定，不套呼吸模板。
5. 纯镜头平移需求且主体明确静止：说明静止依据，交本地平移方案，不强加表演或调用模型。

校验JSON/时间范围只能发现格式和越界，不证明上表物理关系或画面效果成立。实际图片覆盖核对与生成后审片仍由导演完成。
