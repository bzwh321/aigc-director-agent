# 表情与动作联合设计

适用：角色身份参考图的默认情绪与当前故事不同；角色替换；靠近面部、反应镜头或攻击意图需要被观众读懂的动作段。
来源：2026-10-14用户确认鲸鱼娘造型，同时要求复刻兵长攻击段的凶狠表情；参考视频 BV1JTmaYLEP2 的约40.85–44.95秒。
状态：用户要求已确认，参考片已经取帧检查；以下为设计方法，尚无本案例生成视频与人审效果证据。

## 从意图推导表演，而不是复制一张脸

1. 区分身份不变项与表演可变量。脸型、虹膜颜色、发型和体型属于身份；眉眼张力、注视目标、嘴形、头颈姿态和呼吸随意图变化。批准造型不等于批准设定图的笑脸用于所有镜头。
2. 先写“想对谁做什么”，再写可见部位。例如决意攻击与惊恐都可能睁眼露齿；靠眉的方向、注视稳定性、嘴角/下颌张力及躯干朝向区分，不能仅要求“眼睛大、嘴张开”。这些是可选表达手段，不是固定情绪编码。
3. 表情加入同一动作卡：起态、触发、眉/眼/口/头颈、注视目标、开始/峰值/保持或回落、与身体事件的关系。节拍服务当前故事，不强制每次先蓄力再吼叫。
4. 按景别分配表达。远景以轮廓和整体姿态为主，近景再给眼神、牙关和细微表情；不要在几像素的脸上堆无法验收的微表情要求。
5. 同步不等于同频。人物已锁定目标、身体随后加速、头发再因惯性跟随，可以存在有因果的先后；不要让眉眼、嘴、手脚、衣物每一帧机械一起抖动。
6. 角色比例变化时保留动作目的与因果，重新审查肢体可达性和表情可读性。Q版角色不应为了贴合原片骨架被拉成长腿；强烈表情也不能靠换脸、改眼色或改变年龄实现。

## 参考片到新片的检查

- 对多个原始画面取样，分别标主体运动、机位变化、切镜、气流/烟雾及可见反应。硬切到特写不应被改写成一台摄影机连续推近。
- 身份图、表情目标、动态参考分工明确：身份图不锁死微笑，动态参考不带入旧角色脸。表情设计板只用于对齐设计，单张拼贴不自动成为可执行时间轴或多个人物输入。
- 精确事件须密集复核。浏览器寻址时间、录制文件时间和源文件帧时间可能不同；只在检查过的精度内描述，不伪造逐帧对齐或真实速度。
- 复核身体和环境响应是否支持表情。单独的“凶脸”不能补救缺少突进、目标关系和受力依据的动作。

## 审片与沉淀

检查身份稳定、情绪是否误读、眼神是否有对象、嘴部是否无故循环、表情能否被当前景别看见，以及切镜后是否继续同一个行动意图。
只把复核到的成败写成经验：记录输入版本、实际结果和用户反馈；未生成标设计候选，导演自审与用户验收分开。钩锁、绿雾或凶狠表情只属于本案例，不转成所有动作的通用配方。
