# 从静态图推导各主体动作

V3.1，2026-10-13。以下为本项目综合方法；开源技术事实与我们的导演推导分开见 open-source-learning.md。不是从单张图恢复唯一真实运动，也不是运动模型的效果保证。

## 1. 先读图，不先写动词

先全图看主次，再扫前景、中景、远景、边缘、雾中/暗部露出的轮廓。沿用场景 subject_audit，新增实际图中遗漏的主体ID，不替换原ID。每项记录：

- 位置/景深与可见特征，必要时给框或局部标注；遮罩是可选辅助，不必为每张图运行分割。
- 起始姿态、朝向、部件层级；左右优先以画面或主体自身坐标说清，不能混用。
- 接地、悬挂、漂浮、抓持、连接、接触、遮挡关系；每个判断标 visible / upstream / assumed / unknown。
- 当前生命/工作状态、叙事作用和注意力优先级。固定设施、活体甲壳、柔性组织不可因颜色相近而合并。

同类无独立事件的远景人群可以作为群组设计错峰节奏，但执行模型需要保持人数、或个体有独立路径/身份/接触时要拆ID。重复粒子不逐粒编号。图中未出现的支点、手指或背面结构不能伪称观察结果。

## 2. 为动作找依据

逐主体问：它想做什么/被什么推动？现有姿态允许什么？周围空间允许到哪里？这个变化让观众理解什么？

| 主体机制 | 推导重点 | 常见误判 |
|---|---|---|
| 人/动物/机器人 | 目的、注意对象、视线、预备、关节、身体重心、落脚/抓握 | 整体滑移冒充走路；一开始就跳到不可能姿态 |
| 机械/刚体 | 整体平移或旋转、已有轴/轨道、驱动、限位、载荷 | 金属融化；没有铰链却任意折弯；刚体被一概冻结 |
| 漂浮/悬挂物 | 水面/重力/张力、接触、约束、相对岸体或锚点的位置 | 岸上物体跟着水起伏；新增系泊绳；穿水穿墙 |
| 布、植被、柔性组织 | 根部/固定端、自由端、形变区域、迟滞和恢复 | 全部同频同幅；根部漂移；骨架像布一样变软 |
| 风、水、烟、光等场 | 来源、主方向、局部扰动、遮挡、持续或脉冲 | 整屏呼吸/闪烁替代局部变化；无关介质都受同一节奏控制 |
| 固定背景 | 稳定参照、受力是否足够、镜头引起的屏幕运动 | 把“稳定几何”写成“无论镜头怎么动都锁死屏幕像素” |

这些是提问维度，不是按类别自动指定动作。故事明确死亡、休眠、伪装静止时，不自动增加呼吸。大小不能单独推出精确周期、重量和阻尼；无测量时用相对速度/幅度并标设计选择。

## 3. 一张动作卡，分清三个坐标层

每个主体给一张动作卡：

> 为什么动/不动 → 哪个部位 → 从什么状态出发 → 相对谁、沿什么路径 → 怎么加减速 → 何时/几次 → 受什么限制 → 如何停、停在哪里 → 观众看什么确认。

分开世界空间中的主体位置、主体内部关节/材料变化，以及最终屏幕轨迹。屏幕上的箭头只描述投影，不证明物体真的向深处移动、转身或产生三维视差。必须揭示新表面/深度遮挡的运动，不能只给二维平移。

对人物，不是每次强制“先眼睛再头再肩”，而是按动作目的选择可读的预备与跟随；急促反应与克制回望可以不同。接触动作把双方一起设计：接近→对齐→接触→受力/承载改变→释放/保持，避免一个对象已移动另一个仍牢固抓住。路径交叉时说明谁先经过、谁在前、谁暂停。

## 4. 做全图因果图和注意力安排

用最少关系描述，如“海面 W01 → 船 B01 → 可见绳 R01”，固定岸 Q01 作为参照。边有依据、响应延迟和保持项；关系未知就不靠假连接强行联动。可以有多个独立驱动，不建立虚假的全场同频。

主事件与次级响应层级清楚，不意味着只允许一个物体动。高潮时降低无关动作显著性，但不可删掉必要的接触响应或让应表现活着的主体冻结。保留因果链最短可读证据；容量不足时向导演提出分镜/简化，而非暗改叙事。

## 5. 编排时间，特别是停止

选择持续、单次、周期、间歇、分步或到位保持。镜头可以截取长周期中段，不强迫8秒内完成整个呼吸/潮汐。

- 串行：前一承重动作完成才触发下一步；例如解锁后才能抬升。
- 并行：可独立持续，如环境风和人的凝视。
- 错峰：起步不同但允许重叠，如两名路人依次通过；错峰不等于等前者走完整段。

时间段涵盖本镜0到结束，每个主体包括明确的预持/动作/末态或持续说明。对“抬升后停住”，到位和停后保持都必须在最终剪辑中可见；受其带动的部件逐渐停稳，独立水面仍可继续。阶段秒数是计划，不冒称模型硬控制；需要精确同步时交给节点/剪辑评估能力。

## 6. 交接与实际审片

给提示词角色的是目标主体、动/不动理由、时间形态、关键阶段、相对路径、接触/遮挡、不变项和可见验收，不是重复全部物理长文。逐条从动作反查主体ID，再从原图查有无遗漏。

先查静态输入的结构是否支持动作。复杂接触、三维路线或多主体遮挡优先评估真实预演；遮罩、轨迹、姿态、深度图仅在所选节点确实接收时才称控制输入。不支持的控制只能作为设计/验收参考，不能声称已传进模型。

实际审片至少包含动作前、承重事件、停止/末态及正常速度连续播放；对象跟踪/光流可辅助，不替代身份、接触和表达判断。相对稳定参照核对，区分镜头移动、遮挡出现和主体本身运动。未知/假设未解决的承重动作不能标为已完成设计。
