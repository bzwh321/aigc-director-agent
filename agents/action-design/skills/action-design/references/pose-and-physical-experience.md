# 姿势、受力与身体经验

来源：鲸鱼娘镜头多轮姿态纠正，用户在2026-10-14认可03e-02后明确要求记录。方法获得用户认可；案例静态通过，不等于生物力学仿真或动态视频通过。

## 姿势是动作中的一刻

先明确人物在准备、受拉、蓄力、释放、接触还是恢复阶段。静态姿势应能解释上一刻如何到达、下一刻如何继续，不能让下一拍依赖关节跳变或肢体穿透。

按同一因果链推导并审核：

1. 外力与接触：力从哪里来、作用在哪里、朝哪里，支撑/锚点是否存在、张力是否建立；与角色主动动作区分。
2. 整身响应：重心相对支撑、骨盆和胸肩的位移/转动、头与四肢的跟随。空中不套用站立平衡规则；牵引点位置也不单独决定姿态，需结合已有运动和主动控制。
3. 关节路径：沿肩—肘—腕、髋—膝—踝检查连续性、活动空间和握持；分别记录身体前后、相对头部前后及相机遮挡。不能用画面左右替代身体左右或空间前后。
4. 肌肉功能：明确哪些身体段主动发力、哪些稳定关节、哪些随外力被动运动；检查肌肉长度/张力变化、躯干控制和负重表现是否与动作阶段相容。依据可见轮廓、关节和接触判断；看不清时保留不确定，不从单帧杜撰精确肌肉激活量。
5. 连续动作：明确蓄力如何释放、受力如何转移、惯性如何收住。静态只验证姿态可读性和合理性，速度、加速度、真实发力与时序需后续连续帧验证。

美术比例与力学同时成立：可按人物设定塑造修长、轻盈和优美的轮廓，肌肉有力不等于四肢必须粗壮。比例精修后重新检查关节、透视、握持和牵引关系，避免为了美化破坏已校准姿态。

## 纠错与积累

### 从静态认可到持续运动（2026-10-15 B段失败校准）

用户指出已生成B段贴图感强：身体长期保持同一蓄刀剪影，主要整体移动/放大，肌肉与关节的受力调整不足。静态姿势认可不代表要求动态全程冻结。将运动拆成整体轨迹与局部状态变化两条耦合链：受拉→被动滞后→主动稳定/配重→蓄力。写清关节相对角度和身体段的可见变化，不只写“所有肌肉运动”；部分肌肉承担稳定、可近似等长收缩，不需每块都可见收缩或抖动。

固定相机与焦距时，人物向摄影机逼近通常投影由小变大；用光轴深度而非人物到目标的距离建立尺度预期。针孔近似h=fH/Z仅适用于相应投影尺度，转身、弯腿与遮挡改变包围框。需同时检查局部透视、遮挡、身体段相对变化与固定环境参照，不能靠整图放大冒充真实接近，也不强求远处人物发生夸张透视变化。

审核时比较初露、中段、近端，区分相机运动、主体空间位移和关节变化。若去除整体平移/缩放后仍近乎相同的剪影，即使脸、刀、衣服稳定，也不能判动作通过。保持人物美术比例与真实透视的平衡，不能让近腿膨大后称为力量感。

本次失败和新方案均有边界：用户对贴图问题的反馈已确认；新动作合同尚未生成验证。不要把提示词改得更细当作模型能力已解决。

每次遇到不熟悉的动作，先定位具体知识缺口，按需查真实动作参考、运动/解剖资料或已验证案例；不自动开启后台学习、下载或生成。可用工具入口见 [开源学习索引](open-source-learning.md)，工具输出不替代空间与因果判断。

一条经验记录：动作与阶段、参考出处/时间点、可见事实、推断与未知、失败原因、修正及审核证据、适用条件与反例。只有实际验证过的范围才标为通过；保留失败与成功版本以比较。优先沉淀可迁移方法，具体姿势保留在案例中。

本例反例：前臂在头后与手腕在头后是不同空间关系；钢索绷紧不足以证明腰部受拉姿态；锁定错误躯干和腿、只改手臂无法纠正整身动作。成功修正允许整身重设，再局部调整腿部美术比例。具体案例见 [牵引点与身体动力链](grapple-traction-sword-load.md)。
