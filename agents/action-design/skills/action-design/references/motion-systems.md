# 已确认的整体运动、生命节律与物理关系经验

## 把整张图理解为一个相互作用的系统

先按 `../../../../../references/subject-intent-motion-review.md` 接收/补齐当前实际图片的主体表与绘制审核。每个主体都需有运动或静止的决定及理由，含远景、暗部和雾中露出的肢体。把主体ID对应到驱动力、联动和保持项；不能只设计几个显眼主体，也不能把“刚性不变形”写成“所有硬壳都不许位移”。不清楚身份或连接时明确疑点，不默认为静态背景。

先理解场景为什么处于当前状态，再决定哪里动、怎样动以及如何影响邻近事物。主体、环境、摄影机分开描述是为了核对职责；实际设计仍需把它们放回同一个连续空间与时间。让观众读到风、水、重量、生命和连接关系，不把各处运动作为彼此无关的特效。

每镜先选主要驱动力，例如风浪、呼吸、机械传动或异常重力，写出简短因果链：**驱动力 → 直接响应 → 经接触/连接传递的次级响应 → 衰减与保持项**。允许存在独立驱动力，例如沙尘受风驱动、虫巢呼吸来自生命活动；不要强行让整幅画共用一个振荡节拍。

- **先认清对象与连接。** 区分固定地基、漂浮物、铰接部件、悬挂物、刚性骨架、柔性组织和介质，确认真实可见的支撑、接触面、系泊与遮挡。来源不清标为假设；不能凭物件名称把石质码头当浮桥，或新增看不见的绳索来凑联动。要改变已认可结构时先交总控处理。
- **让响应符合材料、质量和约束。** 漂浮物可升降和俯仰，刚性部件整体位移/转动而不局部融化，软膜可形变，重物响应更缓，连接带来牵制、延迟和衰减。低幅运动也应在最终取用片段中可见，不将“微动”写成实际冻结。
- **区分主运动与次级响应。** 主要变化负责故事与视觉焦点，次级运动解释其力量和存在。时间安排说明先后、方向、相位差、幅度关系与落稳/持续状态。不同物件不能无理由同时起伏，也不应有明显受力的部件完全不响应。
- **保持项说明为什么不动。** 固定基础和未受影响的建筑保持稳定；与运动生命体相连的刚性模块可以随承载体微量整体运动，但自身形状、比例与连接不能漂移。避免一条“所有建筑都固定”与主体动作相互冲突。
- **摄影机运动另算。** 镜头平移、旋转或缩放不能替代场景内部相对运动。观看波浪与船、薄膜与骨架等局部关系，确认运动不是整图共同缩放。

## 活体场景的呼吸感

当故事将虫巢、巨型生物或生物机械建筑设定为活体时，明确它怎样被看出仍然活着；只流动的背景雾不足以保证生命感。呼吸可以作为低强度表达，也可按物种/故事选择蠕动、脉冲或别的生命活动；休眠、死亡或伪装静止应服从剧情，不强制每个生物都呼吸。

呼吸先有一个具体可见的组织区域与体积变化：膜囊缓慢充盈/回落、薄膜张力改变、连接组织牵拉和恢复。相关区域共享一个有传播与滞后的节律；有明确结构联系才联动，不把独立巢囊都做成同幅同步气球。硬甲、梁架保持材质刚性，允许必要的微小整体跟随，不能把整座建筑等比例鼓缩。

空气或粒子只在存在合理局部作用时响应，例如气口附近凝雾轻轻排出或薄尘被扰动；远处沙尘仍按环境风向运动，不随呼吸整屏闪动。呼吸通常偏慢、克制且带重量，可从周期中间进入镜头，不要求短短一镜强行完成一整次明显吸吐；剪辑也要保留能读出变化的区间。

条件性例子（学习关系，不照搬物件）：

- 海浪推动真实漂浮物 → 船/浮桥升降与轻微俯仰 → 已存在的系泊绳受牵引、间歇绷紧 → 固定岸体稳定。岸上的艇和固定台阶不能随海面整体晃动。
- 风推进沙尘 → 尘流遇车体与支撑发生遮挡、绕流或局部沉降；与此同时，活体虫巢的膜囊有低幅呼吸 → 相连薄膜出现迟滞张力变化。沙尘与呼吸是同一场景中两个相容、但不必同频的过程。

## 可审阅的运动说明

每镜用少量文字或 `motion_system` 记录：故事/生命状态、主要驱动力、具体可见运动区域、因果链、主次与相位、接触/支撑关系、保持项及原因、摄影机、最终片段应看见的证据。字段按实际需要填写，不要求补不存在的物理关系，也不新增人审关卡。

逐主体补上时间形态：持续、单次、周期、间歇、分步或到位保持，并写起始状态、触发/开始、路径与目标、速度变化、动作次数、停止与停后保持。不要因镜头连续就要求主体一直动。若设计“上移至一个参照位置后停住”，合同、提示词和取段都要包含到位与保持；受其带动的部件与独立风浪分别说明何时停止或继续。具体推导与示例沿用共用逐主体审核协议。

自检以关系成立为准：去掉声音后能否读出主要变化及其原因？受力/连接处是否连续？漂浮物有没有穿水、穿岸或脱离约束？柔性组织是否活动而骨架没有变软？生命感是否真出现在主体而非只靠雾？巨大物体有没有轻飘或急促抽动？局部变化在成片取用时长内是否可见？提示词写好只代表设计完成，实际生成后仍需看片验证。

方法来源：2026-10-12用户关于“海水带动浮桥”“一个图是一个整体”“虫巢里面应该有呼吸感”的指导。属于已确认设计原则，不是已验证的视频效果；具体场景要重新推导。

## 时轴与实现

以锁定场景和时轴为输入，逐秒写预备、移动、接触、受力、释放、缓冲与停稳。主体、摄影机、背景独立运动分开。多人具有独立路径、速度和相位，避免全体同步起步；背景人不能在中央消失或换装。
运镜明确旋转pan/tilt/roll、物理位移dolly/truck/pedestal/crane、焦段zoom。微小平移不强求夸张视差，固定场景几何/深度/尺度不随镜头扭曲，运镜停止后刚性背景停止屏幕漂移。
复杂接触、机械、多人调度先做能检查的真实运动预演。平移一张图片、溶解或模糊不能作为身体动作与真实视差的证据。第一视角关键手部和接触物一起表现，不能用剪贴手代替主动作。
空间或时间不够时，向总控提出拆镜/减少动作/修场景方案，不在合同里偷偷改变时轴。音效同步点交回声音角色。
输出每镜 beats[]（start、end、subject、camera、contact）和 previs（required、path、status、验收依据），所有时间相对本镜，须覆盖起止且不超出锁定时长。
