# 动作提示词编译与案例校准
来源：2026-10-15鲸鱼娘B段实际失败视频与用户反馈。状态：设计方法修订，尚无新动态验证。

## 编译方法
先做主体下的主要可见部件覆盖：把眼眉/表情、头颈、肩肘腕和握持、胸腹腰胯、髋膝踝及衣物道具按实际镜头列出。每项有相对位置变化、稳定或响应及可见证据，再按同一驱动链编译成连贯提示词。整体身份不是最小动作审核单元；部件不是独立自由运动的角色。人物全身移动不等于部件动作已完成。
1. 分开不变与变化：保持身份、服饰、道具数量、连接和必要前后关系；允许关节角度、躯干扭转、局部姿势与投影尺度变化。认可姿势只约束一个关键阶段。
2. 先写因果：谁因什么力或意图，从何处到何处，造成什么结果；再补次级运动。
3. 写状态差：每阶段有驱动、身体段响应、相对上一阶段的变化、可见结果和末态。不要多个阶段都重复“保持姿势向前飞”。
4. 肌肉功能译成可见表现：骨盆先移、胸肩滞后、躯干收稳、髋膝配重、肩肘腕收拢。不要堆肌肉名称或要求全身抖动；稳定性收缩不一定产生明显位移。
5. 将空间路径与相机分开：先明确机位和焦距，再写人物远中近阶段的大小、位置及真实遮挡变化。固定镜头下主体靠近变大不等于整图zoom，也不是各部位永远同倍率伸缩。
6. 分配参考职责：脸部特写若将宽镜生成拉成连续推近，应移到独立近景任务。普通参考图不能承诺中间硬时间戳，不用静态幻灯片冒充动态参考。
7. 查约束冲突：不能同时锁死每帧姿势并要求全身关节运动；先修正正面指令，再列针对实际错误的短禁止项。
8. 每个核心动作配可观察验收，提示词完成仅标设计候选，不宣称视频能力已验证。

## 设计校准题（不调用模型）
- 飞向镜头同时要求每帧同姿势：识别冲突，开放关节与躯干。
- 固定相机同时要求全程dolly：择一或明确分阶段，不能混称。
- 后继脸部特写：不作为主体宽镜同等构图权威。
- 人物剪影不变、只有头发和雾动：身体动作判未通过。
- 所有关节乱动、无受力原因：也判失败。
- 某身体段稳定不大动：按动作阶段判断，不能机械要求所有部位都动。
