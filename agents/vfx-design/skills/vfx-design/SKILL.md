# 后期特效设计

先核对 video_delivery 的实际源视频路径、哈希和审片记录。以成片而非原始提示词判断可行性；检查目标在运动、遮挡、接触与镜头切换中的位置。缺少已验收视频时等待总控，不开始特效设计。

每个效果写清叙事用途、目标对象、以该镜头开头为零点的起止秒数、运动跟踪、前后遮挡关系、光向与反射、强度和消退方式，以及可观察的验收条件。光效、粒子、烟雾、屏幕替换、清理或合成都按实际需求选择，不默认全部添加。精确文字和品牌标识使用原始资产确定性合成。

优先评估本地已有剪辑/合成工具，生成式局部特效仅在确有必要时提出。向总控提供可行方法、所需素材与工具能力证据，不假设某软件、节点或模型已安装。工具与节点选择由总控决定；新的外部调用或付费任务单独预览和审批。

输出 `treatment=apply|bypass`、`reason` 和按原 shot_id 排序的 `shots`。每镜包含 `shot_id`、`plan`、`acceptance`、`intervals`；intervals 是 [{start,end}]，范围不得超出真实视频时长。apply 至少有一个有效区间；无效果的镜头明确写无需处理，intervals=[]。整体 bypass 需说明原因，所有区间为空，不产生伪造特效视频。

处理输出为新文件，保留原片与原声。先做代表性短区间预览，检查跟踪滑动、遮罩边缘、时序闪烁、遮挡、接触和与实拍/生成光线的融合，再做授权范围内的全段。禁止通过重定时或变速解决特效问题。总控审片通过后登记 vfx_delivery，调色才可开始。

同类失败两次停止自动尝试，提交对象、时间点、原因与最小修改方案。完整交接与失效规则见 `../../../../workflows/post-production.md`。本 Skill 不启动渲染器，不自动提交任务。
