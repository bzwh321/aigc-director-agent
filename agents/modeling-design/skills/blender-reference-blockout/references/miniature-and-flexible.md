# 可选：微缩观感与柔性构件

只有任务要求时加载。白模阶段不必做完整材质、装饰和物理模拟；也不把微缩风格视为默认。

## 微缩观感

几何仍采用一致作者尺度。用清晰平面、分区主次、有限风格词汇、可信装配和适度圆角形成秩序，不靠无限小物堆叠。展示时再统一材质尺度、主色、柔和光源/环境补光和接触阴影；适量景深可提示模型观感，但另留清晰检查机位。

先区分 L0 体量、L1 轮廓、L2 结构接触、L3 可见细节、L4 表面表现。不是每一层都必须独立审批，而是高层不能替代底层失败。标准器物可复用合格资产；自定义核心形体保留可控轮廓，不由资产库反过来决定题材。

数字微缩展示不等于真实缩尺制造。3D 打印、实物装配、真实受力或建筑使用另外建立壁厚、公差、承重及合规目标。

## 柔性构件

先选行为：刚性贴合、静态塑形、重力定型还是动画模拟。静态抱枕或压缩软物可用手工受力形变，但必须标为 static_authored，不称真实耦合模拟。

需要布料行为时，可用中等密度四边网格 → 初始贴合/预塑形 → 固定/缝合/骨架锚点 → Cloth 与碰撞 → 缓存或选帧冻结 → 厚度/渲染细分；顺序按当前修改器栈验证。高密度渲染细分不应无理由放到模拟前。

褶皱来自固定、压缩、重力、碰撞和运动；拒绝无来源的随机皱纹、浮空、穿插、失去锚点。碰撞距离按尺度调整，不能调大间隙掩盖穿模。初始穿插、法线、厚度、尺度与碰撞体先查，后调质量。

记录：行为类型、刚度/阻尼、固定组、碰撞体/集合、距离、重力/外力、帧范围、缓存及选定帧。改几何或模拟栈可能使缓存失效；保存源模拟，再派生静态冻结副本，跨电脑另核依赖。只测某帧/局部时不宣布整场全帧合格。

局部小样优先于整场反复渲染。玻璃水体、软装或细密实例先验证一个代表件；既有工程只提供方法，不保证同参数对新尺度有效。
