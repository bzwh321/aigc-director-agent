# 根据形体而不是项目名选方法

| 形体特征 | 常用起点 | 白模必须保留 | 常见错误 |
| --- | --- | --- | --- |
| 规则体积/空间占位 | 基本体、参数化网格 | 比例、方位、支撑与负空间 | 把占位立方体当所有最终构件 |
| 旋转体 | 截面旋转/网格旋转 | 口径、内外轮廓、厚度与底部 | 实心圆柱假装空杯，壁厚随意 |
| 管线/弯曲框架/扶手 | 控制曲线＋可控截面 | 连续中心线、弯曲半径、连接 | 交叉圆柱加球掩盖连接 |
| 壳体/曲面板/风格化形体 | 控制网格、截面放样、细分曲面 | 主轮廓、截面过渡、硬软边 | 加密错误轮廓，软成一团 |
| 门窗/面板/机械外壳 | 独立构件、实体化、受控布尔 | 开口、边厚、装配关系 | 暗色贴片假装洞，薄片假装实体 |
| 叶片/阵列/重复构件 | 共享网格、Array/几何节点实例 | 母件参数、间距、实例依赖 | 无理由实现全部实例导致爆量 |
| 有机角色/软形体 | 低模控制笼、曲面/雕刻后整理 | 身份轮廓、主要负空间与部件 | 套默认人形，球堆伪装连续表面 |
| 复杂连续融合体 | 可用的原生融合/布尔/重拓扑 | 设计线和连接连续性 | 以体素分辨率代替结构设计 |

这些是选择依据，不是硬性操作序列。可用资产/程序化工厂只有在拓扑、轮廓、尺度、许可及改造成本合适时优先复用；不用先遍历整个资产库才能做一个简单物体。

## 方法之间的衔接

- 保留可控制的母形体：曲线、截面、低模笼、参数和锚点。局部增加采样，不全局无限细分。
- 布尔、细分、实体化、倒角的顺序按结构决定。先检查非均匀缩放、法线与自交，再调数值。
- 倒角表现材料加工尺度；薄板和厚壳不应一个宽度。不要用 Weighted Normal 或平滑着色掩盖真正的折叠/凹陷。
- 曲面要在转折和接缝处检查连续性；真实独立零件可以分件，不强求所有东西焊成一块。
- 白模保留识别形体、开口和支撑所需细节；螺丝、细纹、标签通常不是白模前置。近景有明确用途时例外。

## 可选程序化后端

原生 `bpy`/几何节点可以完成基础白模，不要求安装 Infinigen。若已安装且验证过工厂：先读相关模块和参数，孤立测试一个代表件，再装配；保留必要材质/标签/实例依赖。不要改全局工厂默认来适配一个项目。

涉及 SDF/体积节点、节点插槽、导出器或新版本 API，先查当前官方文档及实际版本接口。优先把未知点缩小成一个测试，不照抄网上环境路径、内部模块重载或第三方 site-packages 注入。

外部图生三维仅是可选候选，须明确素材上传、费用、拓扑和可编辑性边界；不因本地造型困难而自动切换。
