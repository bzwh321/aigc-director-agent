# 参考图与结构理解

## 参考的职责

先查看本轮原始图片。分别标出哪些决定身份/外轮廓、内部结构/布局、细节、质量或灯光；多个参考冲突时，以用户指定职责与当前明确变化为准，不平均混合成一个形体。

记录四类事实：`source_observed`（图片实际可见）、`user_confirmed`、`design_assumption`、`external_reference`。用户标注优先表达意图；标注线不一定等于中心线、物理长度或背面轮廓。

没有图片时以文字建立设计合同，不伪造视觉证据。图片打不开、被裁切或分辨率不足时说明缺口。新生成的侧视图仍是设计假设，不能反过来证明原始背面。

## 从图像到三维关系

1. 列出外轮廓、主次体积、对称/非对称、开口与遮挡关系。区分负空间和深色材质。
2. 区分连续主体与分装附件：一体弯管、铸壳、实木扶手不必拆成接缝；门、盖、玻璃、软垫通常应保留独立构件。
3. 确定局部前向、支撑面、中心轴和主要截面；椅子相对桌沿定位，灯相对下方功能区定位，而不是逐个猜 XYZ。
4. 判断空间拓扑：是否贯通、层数、入口、转折、支撑、上下到达关系。透视压缩不自动意味着圆环或径向结构。
5. 单图不明确且不同解释会显著改变轮廓或空间用途时，提出少量低细节假设供判断；不要用材质细节拖延真正的结构问题。

## 相机与可比性

真实摄影优先检查地平线、平行方向消失、主体边界、裁切和可见遮挡，再估焦距/距离。正交图中用比例关系；透视图须考虑深度，像素长度不能跨深度平面直接同比。

保存 `ReferenceCamera` 的参数和图幅；可另有 `PresentationCamera`。不要求草图都达到摄影级标定；非一致透视明确采用哪些关系，哪些只作设计解释。

主轮廓比较只能在匹配机位中作；侧后视用于检验三维成立，不当作未拍摄的真实证据。多图互相冲突时先检查拍摄角度、镜头、物体版本和变形状态。

## 输入到造型合同的最小映射

“圆滑但有清晰棱边”应转成连续性、截面与圆角层级，而非全局高细分。
“像参考图”应展开为关键比例、识别特征、开口、组件朝向和遮挡；无需照抄不影响形体的纹理。
“按参考改造”先圈定保留项与变化项，不能把旧生成结果作为未经指定的新权威。

本 Skill 不预设标准人体、家具、建筑、工业产品或卡通角色之间的比例。类别常识只作有来源的设计假设，不能覆盖用户已确定的非人形结构。
