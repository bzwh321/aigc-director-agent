# 尺度、接触与多视图核查

## 尺度来源

优先顺序：当前明确尺寸/图纸 → 可校准测量 → 已知同平面参照 → 有依据的类别默认 → 显式设计假设。无绝对标尺允许相对单位建模，不强迫用户捏造米数。

常规真实空间可约定 1 内部单位 = 1 米，但要保存约定；微观、天文或 stylized 场景按需要另定。场景 Unit Scale 主要改变显示换算，不自动重设物理行为。非均匀缩放会影响实体化/倒角/模拟，不能只看 UI 单位。

绝对长度来自单张透视图时须有额外已知量与校准依据。单图未知背面深度不写成实测。数字美术比例、真实物理尺寸、制造公差是三种不同合同。

## 组件与相对关系

每个必要组件记录：语义 ID、父件/局部前向、尺寸/来源、支撑面、装配锚点、允许变化。组件坐标应由局部关系导出；父件变化时重新解算依赖，不手工挪一堆附件。

N 面板维度用于辅助查局部轴包围盒。世界占地应从求值后的几何与完整世界变换计算；父级、约束、修改器与实例也要考虑。几何节点未实现实例或隐藏依赖未纳入时明确覆盖缺口，不以部分包围盒宣布全场合格。

## 接触分类

- `rigid_fit`：刚性相接，查支撑平面、相向法线、接触区域、间隙与穿插。
- `static_authored`：为当前静态姿态塑形，查受压位置和体积，标明并非动力学。
- `simulated`：保存模拟参数、固定点、碰撞体、帧范围、缓存和选定帧，按范围验证。
- `clearance`：不接触，检查空间间距、功能取用与开合扫掠包络。

容差按作者尺度、形体尺寸、可见距离和用途选，不套固定毫米数。两个 AABB 重叠只提示进一步检查，不能证明真实穿模；最近点很近也不能证明足够支撑、方向正确或动态稳定。

需要细查时用求值网格的曲面查询/碰撞证据结合多视图，复杂非封闭几何不把单一符号距离当真值；明确测试范围和限制。建筑类通行/楼梯/净空需专用流程，不能从视觉合理推断法规合格。

## 检查表

| 层面 | 重点 | 不可替代它的东西 |
| --- | --- | --- |
| 体量/轮廓 | 主比例、负空间、身份特征 | 高采样和更多面数 |
| 结构 | 连续体/分件、孔洞、厚度、背面 | 一张正面漂亮截图 |
| 空间 | 方位、遮挡、层级、连通、锚点 | 单一相机的“看起来差不多” |
| 接触/使用 | 落地、承托、间隙、动作包络 | 最近距离为零 |
| 可编辑性 | 组件语义、母件、参数、依赖 | 合并成一坨高模 |
| 交付 | 保存/重开范围、真实视图、问题 | 脚本没有报错 |

默认白/浅灰材质与中性可读光照；有色区域只有在区分结构时临时使用，不能代替几何。参考机位看相似性；正侧俯/背视与接触近景看三维成立。检查机位清晰，展示景深不作检查证据。

检查状态用 `pass/fail/not_checked/not_applicable`，关键项不能被均分抵消。数值通过、目视通过、用户认可分别记录，未运行的检查留 not_checked。
