# 写实游戏风格

保持剧情、机位、空间结构与资产身份，按写实游戏画面的目标组织表现。允许强化可读性，但不是自动转成卡通或概念插画。

- 材料有明确金属、石材、涂装、织物等差异，表面变化服务功能与故事。不要均匀铺满微小纹理。
- 用轮廓、体块、明暗和颜色帮助辨认通路、目的地和功能区，保持前后尺度与遮挡可信。不要为“游戏感”随意新增路径或改变剧情空间。
- 摄影与景深围绕当前展示任务，关键信息可读而不全图过度锐化；灯光可有风格化取舍，但来源与投影保持一致。
- 若是真正的实时场景工程，性能、模型、贴图和LOD要求由节点/执行角色核对。仅生成一张图时不得声称已经完成引擎搭建或性能优化。

可用 realistic game environment、physically plausible materials、readable environmental composition 等作为表现标签。除非用户要求，不添加游戏HUD、任务标记、图标或界面；也不借此套用特定游戏资产。

与写实电影的区别是表现目标更强调场景阅读与实时美术语言，而非承诺所有游戏图像都不够写实。输出只带本镜风格决定与保持项，交现有人审，不自动重复渲染。
