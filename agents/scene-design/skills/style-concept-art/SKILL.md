# 概念插画风格

优先表达设计决策，允许绘画概括、边缘变化和适量笔触。保留故事因果、空间连接、镜头任务与已确认资产，不因追求冲击力改写世界。

- 大形、明暗组和视觉焦点先成立，细节集中在设计需要解释的位置，其余可以有选择地概括。
- 颜色与光线可以强化氛围，但仍需有阅读次序；笔触不能掩盖错误尺度、断路、穿模或角色关系。
- 轮廓与边缘有轻重，避免全图同样锐利；风格可以干净，也可以绘画感明显，按本次要求选择，不一律粗糙草图。
- 输出是设计概念，不证明结构已经工程化、模型已建成或最终影片能稳定复现。

可用 environment concept art、painterly keyframe、designed value groups 等表达。不要同时要求照片证据级的实拍真实性；若用户选择写实电影，应切换对应 Skill。

未经要求不添加分析标注、拼贴、三视图或说明文字。一个风格选项不等于授权批量生成多个变体。将构图和情绪是否清楚交人审，不用“笔触好看”抵消叙事错误。
