# 二维动画风格

先确认是否需要明显线稿、弱线稿或无轮廓色块，以及背景与人物的概括程度；已有明确参考时直接沿用，不增加固定问卷。

- 用统一线条、轮廓和色块组织主体与空间，线条轻重和细节密度服从叙事焦点。
- 阴影分组保持一致；可有柔和渐变与空气层次，但不无意混成三维塑料高光或实拍噪声。
- 画面可以平面化，尺度、通路、遮挡和角色接触仍需可信。不能把空间关系压扁到不可理解。
- 建筑与人物沿用既定设计；不要默认放大眼睛、改变年龄或加入夸张表情。动画媒介不决定故事必须轻松。

可用 2D animated frame、coherent line and color design、controlled cel-shaded light groups 等表达，按实际选定表现取舍。不自动添加漫画格、对白框、字幕、速度线或印刷网点。

检查视觉语言是否统一、情绪与空间是否可读。静态图不证明动画帧间一致；人物表演与动态制作另交相应角色。只加载本风格，不把其他风格的要求叠加进提示词。
