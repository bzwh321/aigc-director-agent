# 调色风格目录

独立后期风格，不等同场景美术style_id；用grading_style_id选择。本目录没有自动LUT、已处理视频或厂家认证仿真。默认neutral-match；按镜头/任务/项目选择后只读一个Skill。

| ID | 风格 | 主要调节目标 | 不适合直接做什么 |
|---|---|---|---|
| neutral-match | 中性校色与镜头匹配 | 修异常偏色、稳定明暗和关键颜色，保留原表达 | 把夜景拉成白天，把有色光全部消除 |
| arri-inspired | ARRI观感参考 | 自然色彩分离、柔顺高光、克制且有层次的对比 | 将普通AI片当LogC或宣称恢复ARRI动态范围 |
| s-cinetone-inspired | S-Cinetone观感参考 | 肤色/中间调优先，柔和亮部，人像不过橙 | 自动套S-Log3还原；所有肤色统一美白 |
| eterna-inspired | ETERNA观感参考 | 克制色彩、柔和调子、连贯电影段落 | 当成银盐漂白/高反差去饱和；把暗部抬成灰雾 |
| cool-industrial | 冷峻工业科幻 | 环境冷、承重主体与必要暖色保留分离 | 整片染蓝、污染肤色/白色产品/安全标识 |

相机风格是可操作的创意目标，不是厂家完整成像逻辑。先技术校色与镜头匹配，再设计Look；具体参数由实际画面/工作空间决定。
