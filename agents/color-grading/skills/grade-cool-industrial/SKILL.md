# 冷峻工业科幻

版本1.0.0。状态：方法规范，尚未在当前素材上验证。

先完整读取共用调色Skill `../color-grading/SKILL.md` 及其命中的技术流程；仅在已有视频和明确输入解释上应用。本风格不改变输入gamma/gamut，不授权上传/付费，不自带LUT或固定全片参数。

## 目标

环境克制偏冷，人物/信号/暖光按故事需要分离；用明暗和饱和层级形成空间感。

## 操作

1. 先中性校正并确认画面已有光线；列出人物、白色设备、品牌/警示色保护项。
2. 主要在环境阴影和中间调增加有限冷倾向，高光是否冷由实际光源决定。
3. 保留必要暖色焦点或故事信号，通过局部色相/饱和调整避免全片统一蓝染。
4. 深暗区域留结构，检查金属边缘、雾和大渐变的色带，动态蒙版不得污染人物。

## 验收与边界

肤色不青、白物不无故变蓝、安全标识仍可辨；不靠调色移动光源或添加新灯光。这是本库创意方案，不属于某相机厂商。
