# 调色包

保留既有post-production.md字段：treatment、reason、color_pipeline、shots[shot_id, plan, acceptance, intervals]。新增信息可作为其扩展，不另建重复台账。

## 最小记录

- 输入：路径/hash/认可版本、镜头区间、探测证据及解释不确定项。
- color_pipeline：管理方式RCM/ACES/manual/display-referred、输入gamma/gamut/range与依据、工作域、输出目标/监看环境、既有变换和新增变换。没有证据的值写unknown。
- grading_style：目录ID、Skill版本、参考帧/基准镜头、强度选择及受保护颜色。相机参考一律标look-inspired，不标camera-emulation-verified。
- 每镜plan：真实节点顺序/工具及参数、局部蒙版/跟踪、镜头间匹配差异。尚未操作时标planned，不捏造实际数值。
- LUT（如使用）：来源/许可、文件hash、预期输入域与输出域、角色technical/creative、所在节点、是否已烘焙。
- 验收：曝光层次、关键颜色、切镜衔接、动态稳定、输出域/范围；校准监看缺失时明确限制。
- 输出：新版本路径、实际处理状态和前后对照；未执行则没有结果视频，不填假文件或“已完成”。

## 少量人审、不增加流水线

导演合同包含选定风格与保护项，执行先用代表短片预览；正常情况下并入既有合同/最终审核，不把每个节点变成人审门禁。参数或输入变化保存版本，原片不覆盖。bypass仍需理由，区间为空且保留源片。

## 典型错误的处理

| 情况 | 决定 |
|---|---|
| AI MP4想要ARRI感觉，输入未知 | 先解释输入；可做明确假设的保守Look预览，不套LogC4技术LUT |
| 已有正确LogC4素材 | 用匹配的输入转换，创意选择另列；不能混用LogC3 LUT |
| 套LUT后黑位压死/过饱和 | 先排查重复变换、范围和LUT输入域，不继续压低饱和补救错误管线 |
| 两镜一暖一冷 | 核对是否为剧情照明差异；匹配主体关系，不能一律消除冷暖变化 |
| 单帧漂亮但皮肤闪烁 | 检查限定器、跟踪/关键帧和源片闪烁；不宣称单帧验收代表成片通过 |
| 缺软件或自动化接口 | 交付节点/操作方案，说明未实际处理，不伪造一键调色结果 |
