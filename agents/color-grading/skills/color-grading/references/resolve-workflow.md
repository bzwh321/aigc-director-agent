# 达芬奇式调色流程

2026-10-13。一手依据为Blackmagic的Color页面与官方Training入口；以下节点组织为本库建议，不声称是唯一官方标准或当前机器已配置的工程。

## 0. 建立基线

确认任务是方案、短片试调或正式输出。实际修改需读取媒体并保留原片，复制工程/新版本。记录源哈希、镜头区间、fps/时长/尺寸及色彩探测。对外部视频询问生成/导出方式比猜相机更可靠。

选一镜作为匹配基准，另选暗部、肤色、饱和光源、高光、切点和运动代表段。图像或视频参考只定义观感，不用它的文件标签自动解释当前素材。合片按实际切点分镜，不能对整片用一个自动曝光。

## 1. 两条技术路径择一

### A：Resolve Color Management（优先评估）

在项目色彩管理设置中明确输入、时间线与输出。工作空间可选DaVinci Wide Gamut / Intermediate，但不是所有交付都必须此选择。给每个片段指定真实输入色彩空间；自动识别有缺口时逐片处理。输出根据SDR/HDR与监看条件决定，不仅凭扩展名。

若RCM已承担输入与输出转换，不再叠等价Log→709 LUT或重复输出CST。创意节点在既定工作域中调节；LUT若要求其他域，必须有明确的域适配，不能混入默认链。

### B：手动Color Space Transform

明确采用手动管理时，用输入CST把已知素材转到工作域，创意节点后用输出CST转到目标域；记录gamma/gamut、tone mapping及gamut mapping选择。检查项目没有额外重复的自动输出转换。不同节点的参数数值只在相同域/工具版本下可比。

SDR普通AI视频没有理由仅因“电影感”就先标成ARRI LogC4或Sony S-Log3。相机技术LUT只接相匹配的输入；LogC3/AWG3与LogC4/AWG4不可互换。相机观感采用后述风格Skill，不伪造源素材身份。

### 未知/HDR素材

标签缺失或互相冲突时，先向来源核对；经用户认可可做标明假设的短片预览，但不得把预览称正式色准交付。HDR转SDR需要明确tone mapping与目标亮度；不靠改标签完成。不默认HDR化普通SDR片。

## 2. 节点职责模板

`输入解释/转换 → 基础平衡 → 镜头匹配 → 创意Look → 局部保护/细调 → 输出转换 → 导出检查`

RCM承担的转换无需再建重复节点。局部保护可用并行节点/蒙版，具体位置根据操作域与Look选择，并非必须固定串行顺序。

| 节点职责 | 可用控制 | 检查依据 |
|---|---|---|
| 平衡 | Offset、曝光控制、Temp/Tint或色轮 | 波形图与RGB Parade辅助；有色光不机械归零 |
| 对比与层次 | Contrast/Pivot、Curves、必要的HDR轮 | 阴影仍可读，高光不过早硬截；不靠拉曲线修复源片已丢失细节 |
| 匹配 | Gallery Still/Wipe/分屏，逐镜调整 | 基准镜头、皮肤/产品/环境关系，切镜连续观看 |
| Look | 曲线、Hue vs Hue/Sat/Lum、饱和度关系 | 所选风格意图；亮部和暗部不要同一刀切饱和 |
| 局部保护 | Qualifier、Power Window及跟踪 | 检查边缘、遮挡、出入画、关键帧；肤色线不是固定皮肤亮度 |
| 输出 | 明确输出域/范围与编码 | 文件探测＋回导对照，full/video range不一致可造成灰或黑位压死 |

参数先从中性状态起调，记录真实值、域与版本，禁止凭空给“所有镜头+0.3曝光、饱和50”的通用配方。肤色、品牌色、天空/雾等连续渐变尤其检查重度调整产生的色带。

## 3. 最小经济执行

先1个基准镜头和2个差异镜头短片，认可后按场景组复用Look、逐镜保留平衡差异。不要每镜从零创作，也不要复制全部节点后当成已匹配。不靠自动逐帧匹配掩盖灯光跳动。

默认使用本机已有基础工具；没有Resolve时返回可实施的参数/节点方案，并核对可用本地工具。不宣称FFmpeg简单滤镜与Resolve的色彩管理完全等价。工具/版本/付费功能不清则先查，安装或新增费用需另获授权。

## 4. 输出检查

保存项目/调色方案与参数记录；有实际工程导出能力时才交付对应文件，不伪造.drx/.drp。创意LUT不能保存跟踪蒙版、降噪、颗粒、时变关键帧，也不能独自表示完整调色工程。旁路比较时保持同一输出变换。

核对输出没有改镜头顺序、切点、时长、fps或音轨；同帧前后对照与正常速度连续预览一起给。显示器未校准、浏览器/播放器显示差异必须披露，不靠随意改gamma修复所有播放器。
