# ARRI观感参考

版本1.0.0。状态：方法规范，尚未在当前素材上验证。

先完整读取共用调色Skill `../color-grading/SKILL.md` 及其命中的技术流程；仅在已有视频和明确输入解释上应用。本风格不改变输入gamma/gamut，不授权上传/付费，不自带LUT或固定全片参数。

## 目标

亮部柔顺但不灰，饱和颜色之间仍有分离，肤色自然；仅借鉴审美，不复制传感器。

## 操作

1. 完成输入管理与镜头平衡，标明素材不是ARRI时不选LogC输入。
2. 以曲线/高光控制减缓亮部对比，保留中间调主体体积；源片已剪切的亮部不宣称恢复。
3. 查看高饱和光源、皮肤与相邻色，按需控制过强饱和或色相挤压，不全片统一染暖。
4. 保护白色、肤色和既定照明；对比低/中强度短片，选择仍保留自然分离的一版。

## 验收与边界

高光过渡连续，肤色不橙、不粉，阴影不脏；不能称17档动态范围或REVEAL已复现。资料见color-grading/references/camera-color-sources.md。
