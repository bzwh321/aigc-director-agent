# 中性校色与镜头匹配

版本1.0.0。状态：方法规范，尚未在当前素材上验证。

先完整读取共用调色Skill `../color-grading/SKILL.md` 及其命中的技术流程；仅在已有视频和明确输入解释上应用。本风格不改变输入gamma/gamut，不授权上传/付费，不自带LUT或固定全片参数。

## 目标

曝光/白平衡先正确，人物和产品跨镜稳定，照明与昼夜差异仍成立。

## 操作

1. 对照原片/基准镜头和示波器，找出异常曝光与偏色；不以全画平均值自动归中性。
2. 平衡主体中间调、黑白位与对比；局部高光保留纹理，阴影不无条件抬亮。
3. 用相邻镜头分屏匹配肤色、白色纸品与环境关系，饱和度只修明显不一致。
4. 若已满足要求，明确bypass或只处理问题镜头，不为证明调色而添加色偏。

## 验收与边界

肤色自然、产品关键颜色合理，切镜不跳亮度/色温；叙事有色光保留。此风格无统一固定LUT。
