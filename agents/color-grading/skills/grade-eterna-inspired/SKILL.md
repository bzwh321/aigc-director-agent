# ETERNA观感参考

版本1.0.0。状态：方法规范，尚未在当前素材上验证。

先完整读取共用调色Skill `../color-grading/SKILL.md` 及其命中的技术流程；仅在已有视频和明确输入解释上应用。本风格不改变输入gamma/gamut，不授权上传/付费，不自带LUT或固定全片参数。

## 目标

颜色克制但仍可分辨，调子柔和，跨镜连贯优先于孤立单帧强烈。

## 操作

1. 在正确的输入与基准校色上适度降低过于抢眼的色彩强度，不把全片变灰。
2. 减缓过硬对比，保持黑位支撑和阴影结构；不为了柔和统一抬黑。
3. 对故事重点色、肤色和品牌色保留层级；逐镜检查日夜/室内外衔接。
4. 以连续段落比较，不把单帧看似平淡视为失败；若表达需要强烈高反差，由总控另选风格。

## 验收与边界

不是去色加灰雾，不默认加颗粒或银盐漂白效果；不声称复现原厂机内Film Simulation。
