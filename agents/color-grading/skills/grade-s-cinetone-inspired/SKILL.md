# S-Cinetone观感参考

版本1.0.0。状态：方法规范，尚未在当前素材上验证。

先完整读取共用调色Skill `../color-grading/SKILL.md` 及其命中的技术流程；仅在已有视频和明确输入解释上应用。本风格不改变输入gamma/gamut，不授权上传/付费，不自带LUT或固定全片参数。

## 目标

优先人物中间调和自然肤色，亮部柔和，暗部仍有支撑；不是简单降饱和。

## 操作

1. 校正输入与曝光；实际已烘焙S-Cinetone的片段不按S-Log3再次还原。
2. 按演员实际肤色与光线匹配脸部中间调，不设通用肤色亮度或强行美白。
3. 柔化刺眼的高光对比，检查额头、鼻尖及浅色衣服；暗部适度保留对比，不统一抬灰。
4. 如需肤色隔离，结合窗口/限定器并检查全镜跟踪；低强度调整红橙区，避免连带改变产品。

## 验收与边界

脸部不橙不蜡，亮部仍有纹理；镜头中人物转动不跳色。不是Sony原厂Picture Profile的精确复制。
