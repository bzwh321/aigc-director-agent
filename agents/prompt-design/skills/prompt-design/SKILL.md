# 提示词设计 Skill

对照实际输入，分六维写参考项、保持不变、分时序、主体动作、摄影机、禁止项，另列可观察验收标准。每张图/视频职责与端口关联清楚；发生冲突先退回素材设计，不继续堆词。
直接引用锁定镜头时长、人物/道具/空间和动作顺序。不得临时增加场景、人物、动作或未经设计的声音。最终视频提示词与场景阶段局部图片提示词分开命名。
动作合同沿用subject_id，保留每主体动/静、时间形态、动作次数、触发、联动、停止和末态保持。不得把一次动作编译成全程循环，或用“所有建筑/硬壳固定”覆盖应整体运动的主体；未决承重关系返回总控。轨迹/遮罩/预演只有实际节点接收才声明为控制输入。参考 `../../../action-design/skills/action-design/references/action-package.md`。
先产出模型中立合同，节点角色选定模式后按实际模型支持的字段编译，保持语义不变。普通参考尾图不是时间终点；专用首尾帧才提供端点约束；中间参考图不能承诺硬时间戳。
同类失败按身份、数量、空间、接触、动作、摄影机、声音分类，保留版本对照；一次只改一个变量，只有服务实际支持seed时才固定seed。两次相同失败停止自动尝试。
输出每镜 reference_roles、prompt、negative、acceptance，附源版本。需要中英双语时语义对齐，不能在翻译中引入新动作。

## 交接检查

静态图提示词先按 [重绘与局部编辑输入策略](../../../../references/static-generation-input-policy.md) 标明fresh_redraw或local_edit。前者从当前要求和原始参考重新编译，不附带旧生成图或旧提示词修补链；后者才列指定底图、编辑区域与不变项。按参考来源白名单调用，不用最近图片自动包含旧结果。

人物动作生成或贴图式失败修订时，读取 `../../../action-design/skills/action-design/references/action-prompt-translation.md`。将身份/连接不变与关节/躯干可变分开，每阶段描述关键状态差及可见结果；检查参考职责、镜头与身体动作是否互相冲突。具体数字和长禁词表不等于控制能力，编译完成须标待实际视频验证。

使用总控给定的 shot_id，记录当前 revision、直接上游版本与内容哈希。按 `../../../../workflows/production-v2.md` 组织产物。本 Skill 是专业方法，不自动启动其他角色或提交计费任务。
