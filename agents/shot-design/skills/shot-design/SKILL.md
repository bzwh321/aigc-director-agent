# 镜头设计 Skill

输入是已理解的人类目标，不把用户形容词直接堆成提示词。先说明观众必须看见什么，再确定每镜的景别（特写/近景/中景/远景）、视角、主信息、起止状态、切点与时长草案。为镜头分配稳定 shot_id。
有对白/旁白立即向声音角色交接台词与情绪。声音尚未实测时，duration_seconds 标为草案，不自称时轴已锁。用最终对白和反应时间调整镜头，不能强行加速声音。
第一视角先确定摄影机是谁的眼睛，画面是否允许手或身体。第三视角确定轴线、视线、景别和转场动机。每镜一个主要叙事任务，不机械强制所有镜头4秒，也不把多个复杂动作挤进短时长。
选机位时先说明观众站在谁的位置、需要感受到什么，并核对前后镜主体的画面位置与注意力落点。修正身体左右或接触点时，不能仅为证明局部正确擅改已指定的主观视角；同一连续动作优先保持可比较的机位、主体位置和接触点，必要换位需有叙事依据。
输出 shots[] 必须包含 shot_id、purpose、shot_size、perspective、duration_seconds、has_dialogue、transition，另写起止状态与静态素材需求。画分镜时保留上一镜连续性权威；多格图用于审阅，不默认直接作身份参考。

## 交接检查

连续动作、反应或内外视角切换时，读取 [叙事接力与连续性](references/narrative-continuity.md)。每镜写清前镜留下的状态、这一镜新增的信息、下一镜接收的结果；关键因果不得省略。静态画得好不等于分镜顺序可剪。

动作结果尚未展示、运镜启动时机不清、错误尾态被当作目标或组片遗漏因果段时，按需读 [连续动作、一致性与镜头叙事复盘](../../../../references/action-continuity-shot-narrative.md) 的镜头叙事与输入职责部分。按可见事件安排揭示和切点，不把“后撤、变焦、转向”混称，也不为逐张节点展示而打断连续动作。

使用总控给定的 shot_id，记录当前 revision、直接上游版本与内容哈希。按 `../../../../workflows/production-v2.md` 组织产物。本 Skill 是专业方法，不自动启动其他角色或提交计费任务。
