# 静态图输入策略：重绘与局部编辑分流

来源：用户2026-10-17明确要求。适用于本导演工作流的静态图制作，不修改视频原始素材或授权范围。

## 先判模式

- 非局部修改（整身姿态、机位、构图、场景或整体表现重设）：使用 fresh_redraw，重新绘制。不得把上次或更早的生成图作为底图、姿态参考、身份参考或隐含背景参考，即使该图曾局部通过。先从当前用户要求和原始参考重新编译任务。
- 只有用户明确要求局部修改/限定区域编辑时，才使用 local_edit：以上一版中用户指定的图为底图，仅改指定部分，检查未改区域及连续性。
- 用户后来明确指定例外可覆盖本默认，但要记录具体图片及用途；“继续”“再来一版”不是默认允许沿旧图迭代。

## 精简独立输入包

每次仅提供当前目标、当前有效约束、必要原始静态参考和新提示词。原始参考分工为姿态/机位、角色造型、场景/材质；不把不同职责混成一张同时约束所有事情的母版。

fresh_redraw中，之前的生成图仅可在生成完成后做外部评审，不送进生成调用。失败版本、旧提示词整段、已经废止的限制不混入新提示词。原图缺失时优先请求补充或明确说明只用现有原始参考+文字，不能默默换成旧生成图。

“清空上下文”只表示本次输入隔离，不声称删除了会话或模型记忆。有明确本地路径时，使用 referenced_image_paths 白名单，不用 num_last_images_to_include 自动携带近期生成图。

## 记录与审核

任务记录至少包含 mode、参考路径、来源类型、reference_role、排除旧生成图说明、当前提示词。对fresh_redraw逐项核对来源，不把重新上传的旧生成图误标原始素材。使用用户提供的动画/示意图时，姿态与最终写实风格分别指定，不能默认照搬动画比例。

先核对构图/整身状态/关节连接是否符合当前原始参考，再看细节和美术；参考图能提高约束，但不是硬骨架/像素级控制。不因文字正确而判图通过。

沿用既有静态图、合同、最终结果三个人审点和本轮次数/费用限制，不新增固定关卡，不默认生成更多图。保存原版，未经确认不覆盖。
