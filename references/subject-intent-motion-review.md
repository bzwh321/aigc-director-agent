# 导演表达与逐主体审核

来源：2026-10-12用户指导——先问导演要表达什么；图片里的每一个主体先审核其绘制，画出来就要考虑动作，可以不动，但必须检查并说明不动的理由。此为设计方法，不代表现有视频已经验证。

## 先确定表达，再检查实际画面

每镜先用一句话说明：观众先看见什么、随后发现什么、由什么可见证据理解当前事件或生命状态。导演负责这句表达意图，场景角色据此检查视觉呈现，动作角色据此设计变化。设定文字不能代替画面证据。

逐层查看实际原图，而不只回看提示词：前景、中景、远景、雾中和被遮挡的可见部分都要检查。图像生成意外添加的主体也要纳入。每个可辨认、具有独立叙事/生命/受力关系的主体分配稳定 `subject_id`，用位置、景深及可见特征定位；必要时附局部标注，不能只称“背后的东西”。

重复窗格、同类尘粒等可按同一材质/状态/功能分组，不逐像素列单。但前景承重肋架与远景生物肢体即使颜色和形状相近，也不能合为“所有黑色肋架”；同属一个生命体而连接被遮挡时，说明已知与未知，不编造完整解剖。

## 每个主体都经过两次判断

**先审核绘制。** 它是什么、为什么出现在这里、支持什么故事或尺度关系？数量、轮廓、材质、支撑/接触、尺度、遮挡和与其他主体的连接是否成立？分清可见事实、导演设定与不确定推断。无作用或绘制冲突的元素提出具体修订，不靠动效掩盖错误，也不擅自修改已认可素材。

**再决定运动或静止。** 对每个主体选择主动运动、被动响应、局部状态变化、本镜静止或尚待判断，并写理由。结合故事/生命状态、受力连接、重量材质、环境及观看重点作决定，不要求所有主体都动。

- 动：写具体区域、驱动力、方向、节律、幅度关系、相位、关联对象、接触与停止条件，说明最终取用片段应看见什么证据。主动运动和风浪等引发的被动响应分别推导。
- 不动：解释为什么本镜可以静止，例如固定地基未受扰动、死亡/休眠/伏守的已定状态、当前动作停顿或有意延迟揭示；同时检查是否仍需对环境作用作可见被动响应。
- “很远”“被雾挡住”“不想变形”“模型难做”“保持画面稳定”本身不足以解释叙事主体为何不动。若技术或时长限制需要简化，明确牺牲的表达与替代方式，由导演作取舍，不暗中冻结需要表现活着的主体。
- 刚性不等于位置固定。甲壳单节可以保持形状而通过关节转动，机械模块可以被承载体带动；固定建筑与生物硬壳不能用同一条静止约束覆盖。
- 遮挡不等于不存在。决定遮挡中的主体是否运动、哪些可见轮廓会变化、与固定地标的相对位置是否足以读出；只让雾移开不能冒充主体自身在动。未知的画外动作无需擅自补全。

## 动作怎样开始、持续、结束

决定“动”之后，还要选时间形态及原因：持续运动、单次动作、周期运动、间歇动作、分步推进、移动到位后保持，或在本镜保持静止。它们服务不同表达：一次抬升后停住可以暗示察觉/等待，连续漂移可表达异常仍在持续；具体解释由本镜故事决定，不做固定象征词典。

每个主体的动作说明应能回答：镜头开始时处在哪个状态？什么触发变化、何时开始？沿什么路径、移到哪个相对位置？速度是匀速、加速、减速还是阶梯式？持续多久/发生几次？是否回到原位或重复？怎样停止、惯性如何衰减？停止后保持多久，哪些关联主体和环境仍会继续？无可见触发也可由既定生命节律等内因驱动，说明即可。

“往上走一格再停下”的条件性示例：0–0.8秒保持原位 → 0.8–2秒沿竖向移至已指定参照位置 → 2–2.5秒减速停稳 → 2.5–4秒保持新位置；只发生一次、不回弹复位、不循环。这些秒数仅演示描述方法，不是通用模板。“一格”必须对应已有档位、间距或其他可读尺度，没有格线时由导演说明相对位移，不能要求模型凭空画出刻度。

多个主体分别定义时间安排，并核对触发、先后、相位与连带作用。主体到位停住不等于整画面定格；例如水面和雾可继续，受主体带动的连接部件应按约束逐渐停稳。若环境仍施力却要求主体完全不响应，需要有合理固定/阻尼等依据。

提示词区分“连续镜头、无切镜”与“主体一直运动”。不得为所有镜头套用“全程持续运动”“永不停止”“循环呼吸”等默认句，覆盖已经设计的一次动作或停顿。阶段时间是导演目标，不冒称模型能精确按秒执行；实际结果按可见状态转变核验。

剪辑检查动作起止意图：若本镜表达“移动后停住”，最终取段必须让观众看见到位和足够的保持，不能只截移动中段；若只是从长过程取一小段，要明确不展示完整动作，而不是误把被剪掉的停顿判为生成失败。

## 一份简短的主体表贯穿交接

在 scene_package 或制作合同内保存 `subject_audit`，不另建一套重复台账。每项至少能回答：

| 内容 | 用途 |
|---|---|
| subject_id、位置/景深、可见特征 | 从图到提示词和审片能定位同一对象 |
| 表达作用、绘制审核及疑点 | 说明为何存在、画得是否成立 |
| 生命/材料/连接状态 | 为动作建立依据，区分事实与设定 |
| 运动决定、理由、关联主体 | 每个主体都有决定；静止也有原因 |
| 时间形态、起止状态、触发与阶段、次数/重复、到位后保持 | 区分一直动、只动一下、分步动和动后停住 |
| 动作/静止约束、可见验收证据 | 落到提示词、时轴和最终取段 |

可按任务写成紧凑文字或结构化字段，不强制每项都填数值。`尚待判断` 要记录具体缺口，不能计为已完成设计。场景角色负责绘制审核与连接事实，动作角色补运动决定，导演核对表达与全图覆盖；这是一项设计检查，不新增人审关卡。

提交合同前做双向核对：从原图逐主体检查是否都有决定，再从每条提示词约束反查它指向哪些主体。避免“所有建筑固定”“所有硬壳不动”误伤应该整体运动的活体/承载模块。再次检查前中后景，尤其是雾中、暗部、边缘、部分露出的巨大主体。

审片沿用同一主体表：预定运动是否真的发生？动作次数、方向、到位/停止与保持是否符合意图？预定静止是否保持？接触与相位是否合理？导演要表达的信息在最终取用时长内是否可读？全部条目被填写只代表设计覆盖，不等于图像或视频效果已通过。

## 条件性例子：雾后生物肢体

若导演要表达“封锁后的巨物仍然活着”，远景雾后肢体必须单列，先判断其可见节段、与塔楼的遮挡以及生命设定。可让节段保持硬壳形状、在连接处发生缓慢低幅转动，相对固定塔楼产生可辨位移；也可让它伏守不动，但需给出该选择如何服务悬念的理由。不能因前景另一肋架需要稳定，就把远景生命体一并锁死。
