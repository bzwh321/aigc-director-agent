# 每镜最多三次：自审与定向重做

依据：2026-10-12用户明确要求“批准你的制作，如果制作做不好，就重新做直到你的审查通过……每一个镜头最多抽3次”。适用于本自动化Skill中的已获授权制作批次；不是其他项目的无限重试或未来每日收费授权。

- 每个镜头最多3次生成，含首次，最多2次重做；通常5镜最多15次，但仍同时受本批实际批准的总预算约束。通过即停止该镜，不能为了凑次数继续抽。
- 首轮优先覆盖本批各镜；重做前先核对剩余费用与尚未完成的镜头，不把整批预算耗在一镜。预算与次数取更严格边界，不凭“最多3次”擅自扩大已批准金额。
- 每次真实提交前持久化镜头ID、attempt、输入哈希、提示词版本、模型/规格、费用预留与状态。任务返回后立即保存task_id；恢复时查原任务，不以更名、换日期、改seed或prompt版本清零次数。
- 提交超时或未知状态不是新候选。先查询/恢复已有task_id，无法确定是否创建任务时暂停，不再次POST。轮询、下载和本地剪辑不算抽卡，不应重新生成来解决这些问题。
- 明确的账户/权限、参数或服务不支持错误先诊断，不能靠重复提交碰运气；不自动换供应商、模型、画幅、分辨率、片长或升级费用。已明确失败的生成任务计入保守次数账本。
- 导演按合同主体表检查实际视频：主体是否遗漏、动静理由是否兑现、方向/次数/停止与保持、呼吸/机械/环境联动、刚性几何、接触、遮挡和画面质量。模型返回成功只表示产物存在，不表示审查通过。
- 失败先记录可见缺陷与证据时间段，再给最小调整。改变对应提示词/约束/运动幅度或可行的本地剪辑，不自动重新设计已认可图；确需改静态图、核心故事或改变原合同则返回该变更的适用审核。
- 下一次仅重做未通过镜头，保留旧候选及审查理由。不能降低原验收标准来“凑通过”，也不能用全图缩放代替约定主体运动。
- 每镜3次全部用尽仍不合格，状态记为 `exhausted_needs_decision`；预算不足记为 `budget_exhausted`。汇总已通过镜头、未通过项目、已用次数与费用供用户决定，不交付伪装成合格的成片。
- 本地剪接/混音/裁切错误可在不新增模型费用的范围修正，最终仍需整片审查与真实文件交付；最终用户验收不由导演代填。

调用导演与执行器时传入本批授权原话、金额边界、`max_attempts_per_shot=3`、已用次数和候选记录。本Skill的本条有界自审授权优先于旧资料默认“第一次质量不佳即返回用户”；未获批的费用、未知提交状态、权限失败和范围变化不因此放行。
