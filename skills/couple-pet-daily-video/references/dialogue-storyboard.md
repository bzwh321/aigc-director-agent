# 配音与对白分镜

## 先保存原话

保留一份逐字原文，再建立“表演稿”。表演稿可以删口头重复、移动停顿或把一句拆成两拍，但不能偷换观点、关系、称呼或情绪。用户标注“原话必须保留”的句子逐字保留。

## 每条台词的最小字段

| 字段 | 内容 |
|---|---|
| speaker | `speaker_a` / `speaker_b`，以及已确认的猫猪映射 |
| line | 实际配音文本 |
| intent | 这句在关系里要做什么，如试探、吐槽、解释、撒娇、回避 |
| delivery | 音量、速度、重音、气口、是否笑着说或压低声音 |
| timing | 开始、结束、句内停顿；以最终音频为准回写 |
| visible_actor | 当前画面里的说话者、听者或双人 |
| action_cue | 与台词对齐的转头、停顿、靠近、退开、碰触等动作 |
| lip_sync | `required` / `suggested` / `offscreen` / `none` |

## 配音原则

- 默认不预制或外接 TTS。逐镜台词直接进入 H3 全模态原生有声任务，让模型在生成动作和画面的同时完成声音、情绪与动物口型；外部音频输入保持为空。
- 猫默认使用可爱的女性童声，小猪默认使用可爱的男性童声。提示词要同时写明声线、情绪、速度、重音和说话动作，不能只放一行台词期待模型自行决定表演。
- 先把台词拆成少量有作用的短语，再为每一段写可听见的表演变化。例如“压着火、较慢”是起点，“失望并减速”是推进，“警告词加重后停半拍”是落点。不要只写“生气地说”“可爱地说”这种无法检查的单一标签。
- 情绪必须有画面对应：声音压低时眼神或身体收紧，重音出现时头部、爪/蹄或道具动作发生，句末停顿时嘴闭合并保留听者反应。声音与动作不能各自独立表演。
- 原生音频是镜头的一部分。合同和审片都要核对实际说出的字句、发音清晰度、性别与年龄感、音量、口型同步和句末收口；任一项失败都按该视频节点失败处理。
- 先确定谁在说、为什么这样说，再选声音。不要用统一的“可爱童声”抹掉两个人的性格差异。
- 语速服从真实中文口语和动作，不为了塞满画面把停顿全部剪掉。
- 笑声、吸气、犹豫、鼻音等只有在原对话或场景确实需要时保留，不批量装饰。
- 如果使用真人声线复刻、克隆或其他需要授权的声音服务，必须单独确认同意、用途和服务；文字里出现“我老婆”不等于已授权克隆声音。
- H3 生成口型时只允许当前发言者开合嘴。听者用眼神、耳朵、头部和身体反应，不做同步开合嘴。
- 镜头切换不能切掉笑点前的停顿或对方的反应。对白结束后保留足够的动作收尾，避免角色说完立刻冻结。

## 全模态节点字段

每个有对白的节点除最小字段外，再记录：

- `generation_mode: h3_full_modal_native_audio`
- `native_audio: true`
- `external_audio_input: none`
- `voice_profile`：猫/猪、童声性别、情绪、语速与重音
- `emotion_arc`：起始心理、逐短语推进与句末情绪落点
- `prosody_cues`：短语级语速、音量、重音、停顿、呼吸与是否收声
- `spoken_text`：要求 H3 实际说出的逐字台词
- `mouth_visibility`：正面或三分之二正面、无遮挡、可审查
- `audio_visual_action`：与关键词同步的口鼻、头耳、身体和道具动作
- `failure_stop`：错词、漏词、情绪平读或情绪方向错误、无口型、人嘴人牙、双角色同时张嘴或身份漂移即停

## 原生情绪审听

审片时不能只看“有声音、有口型”。至少核对：

- 角色的情绪是否符合这句话在关系中的作用，而不是随机愤怒、撒娇或播音腔；
- 关键短语的重音、停顿和语速变化是否与合同一致；
- 同一角色跨镜的年龄感、性别感、音色和说话习惯是否连续；
- 句末是否完成情绪落点并闭嘴，听者是否得到反应时间；
- 环境声和动作声是否支持表演，没有盖住对白或抢走重音。

文本正确但情绪平直、重音错误、停顿破坏笑点或声音与动作冲突，均不能因为口型存在而通过。

## 声音角色调用要求

每个镜头都调用导演的 `sound-design` 角色。对白镜头由其输出 `voice_performance` 与 `sound_cues`；无对白镜头也要输出接触声、动作声、环境声、静音区和跨镜声音桥。只在分镜表里写一句“可爱童声”不算完成调用。

声音结果必须在动作合同完成后复核同步点，在生成合同中与动作、运镜和场景共享同一时间轴。若原生音频出现机器播报感，可在人审通过后用本地变速做节奏修订；但本地加速是后期选择，不能替代生成前的情绪弧线与韵律设计。本项目已验证 1.20 倍直接加速可改善一集对白节奏并允许自然升调，此数值是当前项目候选，不自动推广到其他视频。

## 建议的节奏形状

日常对话通常可以整理为：场景建立 → 一方起话 → 对方反应/回答 → 关系动作或小反转 → 余韵。它是检查顺序，不是强制五镜模板；短对话可以一镜完成，较长对话可在听者反应处切镜。

最终分镜先服从配音的真实时长，再微调镜头，不用预设秒数硬压台词。
