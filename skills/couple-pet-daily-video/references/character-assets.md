# 角色资产与一致性

## 基准方向

### 当前权威猫 v005

- 来源：用户提供的两张真实幼猫照片为年龄、比例和当时花色的最高权威；成年照片只补充后颈白环与长期身份。
- 年龄与比例：真实长毛幼猫，大耳、大头、小身体、短腿、小白爪；使用原片天然 Q 感，不再额外套通用幼猫模板。
- 脸与眼睛：深黑棕虎斑面罩为主，中央有窄浅色鼻梁/口鼻斑；眼睛为偏浅的灰绿色至蓝绿色幼猫观感。
- 核心辨识度：宽白胸毛连续绕过颈侧，并在背面形成清楚的白色环颈带；不是项圈或围巾。
- 身体花色：背部和外侧以深黑棕为主，暖橘集中在身体侧后方；白色覆盖胸、腹侧、四腿和四爪。
- 尾巴：幼年阶段已蓬松，以深色为主、夹暖棕橘，但不得膨胀为成年最大尾量。
- 权威文件：`../assets/characters/cat-home-childhood-turnaround-v005.png`。

### 历史猫 v001

- 物种与年龄感：真实幼猫，幼态但不是玩偶。
- 外观：橘白双色，圆脸，大而深色的眼睛，小粉鼻；白色口鼻、胸口与四爪，橘色头顶、耳朵外缘、背部和尾巴。
- 体态：短腿、圆润、微蓬松的真实毛发，尾巴可自然竖起。
- 禁止漂移：不变成长毛成年猫、扁脸品种、纯橘猫、卡通大头或塑料毛发。

以上为历史 v001 通用橘白幼猫。它与 v002–v004 均已被 v005 取代，只能用于回看探索过程，不能再作为新视频的猫身份权威来源。

### 历史探索 v002–v004

- 年龄与体态：成年长毛猫，身体圆润宽厚，不能缩成幼猫；Q 化只允许头脸略放大、躯干略紧凑、腿部略短，真实猫科骨骼和重心不变。
- 眼睛与脸：大而圆的浅绿色眼睛；脸部以黑色/深棕虎斑为底，混有不对称暖橘色斑块，鼻口周围有小块浅色，白色长胡须明显。
- 身体花色：黑、深棕、暖橘交错的长毛三花/玳瑁白分区；**脖子有一圈连续的白色长毛围脖，这是核心辨识度**，正面连到宽白胸、侧面绕颈、背面形成明显白色环带；腹侧和四爪也为白色。
- 尾巴：粗大蓬松的羽状长尾，以深黑棕为主，夹有暖棕橘过渡。
- 禁止漂移：不变成橘白幼猫、短毛猫、纯玳瑁无白胸、奶牛猫、波斯扁脸、动漫大眼或玩偶。

### 猪角色

- 物种与年龄感：真实淡粉白小香猪/迷你猪幼崽。
- 外观：圆黑眼、鲑粉色鼻盘、小而竖的三角耳、皮肤表面有极短浅色绒毛。
- 体态：身体紧凑圆润、短腿、小蹄、自然幼崽比例。
- 禁止漂移：不变成黑花猪、成年猪、卡通猪鼻、橡胶皮肤或玩偶材质。

两者的“Q”只来自幼崽比例、圆润轮廓和表情可读性；质感、光影、关节、脚掌/蹄和接触阴影保持写实摄影逻辑。

## 版本与采用

- 新生成图片先标为候选，用户认可后才成为 `approved` 身份基准。
- 不覆盖已认可版本；修改时升 `v002`、`v003`。
- 每集记录实际采用的文件名和哈希。若只改变表情或姿势而身份不变，保留同一角色版本并另存镜头资产。
- 猫或猪分别代表夫妻中的谁，不从性别、物种或对白推断。首次由用户确认后写入系列设定；单集临时互换必须显式记录。
