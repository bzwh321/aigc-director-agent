# 人物对白生产：画面筛选与原声对口型

用户确认日期：2026-10-08。此规则用于已定配音、需要镜头动作与原音嘴型同步的项目，不替代逐轮预算批准。

## 默认流程

1. 锁定台词、原声、每句实际时长和说话人；句内导演节拍与实测录音边界分别标明。
2. H3等合适模型负责动作、表情、运镜和空间。人物嘴部应尽量清晰；提示词说话时段只是辅助，不能当成精确对口型。
3. 只对视觉已通过的素材付口型修复费。外景、画外音、第一视角看不到自身嘴巴、纯聆听人物不需要对口型。
4. 用已有RunningHub“可灵人脸识别→可灵对口型”节点。识别返回sessionId、faceId、脸图和时间区间，必须对照选定角色，不能把默认示例ID带入真实任务。
5. 当前接口一次只支持一个人。双人轮流说话，按发言区间切分，各自原录音驱动选定人脸，然后原速拼回；若需要连续整段逐人处理，后续一次应以最新修复视频重新识别，避免覆盖前次修改。
6. 先验收局部脸部重绘、逐句口型、旁人是否误动嘴、动作背景是否保留，再合片、升分辨率和补帧。自动音轨相关性只是验证声音内容，不能用作嘴型通过证据。

## 关键参数

- 可灵对口型接受外部视频，具体时长/尺寸上限每次按官方接口核对；本次样例采用1280×720、25fps、4.48秒静音视频。
- soundStartTime、soundEndTime、soundInsertTime单位为毫秒。样例分别0、4480、0。
- 上传原WAV时不传TTS示例audioId；soundVolume=1，originalAudioVolume=0，避免双重声音。
- 本次识别face0是智子、face1是程心，属于该素材的返回结果，禁止泛化到其他镜头。
- 不把几个角色的整段混音交给单个人脸。遮挡、侧脸和激烈动作可能导致失败或脸部重绘，应保持完整原片可回退。
